# GitHub 发布范围与凭据边界

本次发布目标是在用户 GitHub 账号下创建一个新的项目仓库，用于保存 **Video Localizer** 的程序源码、便携版使用说明、构建脚本和发行包下载资产。上传过程将采用小批量策略，避免一次性推送过大的对象，并尽量通过 GitHub Release 上传压缩发行包，而不是把大体积二进制直接放入 Git 历史。

| 类别 | 处理方式 |
|---|---|
| 源码与脚本 | 上传到仓库 Git 树，便于后续维护 |
| 使用说明与验证报告 | 上传到仓库文档目录或根目录 |
| 便携压缩包 | 作为 Release 资产上传，避免污染 Git 历史 |
| `.env.local` 与密钥 | 不上传，使用模板文件替代 |
| 任务数据库与历史输出 | 不上传，避免泄露用户视频记录 |
| 下载视频、输出视频、日志 | 默认不上传，只上传最终发行包 |

> 用户提供的 GitHub 临时令牌只作为本次 API 调用凭据使用。该令牌不会写入源码、README、提交记录、脚本、日志文件或仓库配置。任务完成后将清理当前 PowerShell 会话中的令牌变量。

建议仓库名称使用 `video-localizer-windows`。如果该名称已存在，将自动尝试 `video-localizer-windows-portable` 或带日期后缀的名称。
